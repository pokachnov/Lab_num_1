## Назначение

Программа читает с клавиатуры массив A, а затем параметры a, x, h и длину m и вычисляет массив B по формуле `B[i] = 1.25 * sin(3 * a * x - i * h)`. Затем она выполняет три операции: удаляет из B отрицательные элементы строго левее первого максимума, вставляет в конец A копию последнего элемента и заменяет на 1 те элементы A, у которых `fabs(A[i]) < 1`. После построения и после каждой операции программа печатает соответствующий массив с тремя знаками после запятой.

## Ограничения

- Длина массива A (n) и длина массива B (m) — целые числа от 1 до 20.
- Емкость каждого из массивов — 20 элементов (`CAPACITY`).
- Если `scanf` прочитал меньше значений, чем требовалось, или n либо m вне диапазона от 1 до 20, программа выводит `ошибка ввода` и завершается с кодом 1.
- Если длина A равна 20, вставка не выполняется и выводится `нет места для вставки`.

## Сборка

Команда выполняется из каталога работы:

```bash
gcc -Wall -Wextra -Werror -o app src/main.c src/arrays.c -lm
```

## Запуск

```bash
./app
```

Данные вводятся с клавиатуры. Подсказки перед вводом не выводятся.

## Формат ввода и вывода

Ввод:

1. Целое число n — длина массива A (`%d`).
2. n вещественных чисел — элементы массива A (`%lf`).
3. Целое число m — длина массива B (`%d`).
4. Три вещественных числа a, x, h — параметры формулы (`%lf`).

Числа разделяются пробелами или переводами строки.

Вывод: десять строк — подпись и массив для каждого из пяти шагов (`A:`, `B:`, `B после удаления:`, `A после вставки:`, `A после изменения:`). Каждый элемент печатается с тремя знаками после запятой (`%.3lf`), элементы одной строки разделяются одним пробелом.

Сообщения:

- `ошибка ввода` — ошибка чтения или n, m вне диапазона; код завершения 1.
- `массив пуст` — после удаления в B не осталось элементов (для этого варианта недостижимо: первый максимум не удаляется).
- `операция невозможна` — в массиве нет ориентира (для этого варианта недостижимо: при m ≥ 1 первый максимум всегда существует).
- `нет места для вставки` — длина A равна 20, вставка не выполнена.

Пример ввода:

```text
5
0.5 -3 2 7 -0.2
8
-1 1 -1
```

Вывод для этого примера:

```text
A:
0.500 -3.000 2.000 7.000 -0.200
B:
-0.176 -1.137 -1.052 0.000 1.052 1.137 0.176 -0.946
B после удаления:
0.000 1.052 1.137 0.176 -0.946
A после вставки:
0.500 -3.000 2.000 7.000 -0.200 -0.200
A после изменения:
1.000 -3.000 2.000 7.000 1.000 1.000
```

## Тесты

Тесты приведены в файле [`test_cases.md`](test_cases.md). Набор содержит:

- нормальные данные: разные длины n и m, выполняются все три операции; удаление не убирает ни одного элемента; удаляются все элементы слева от максимума;
- граничные данные: n = 1 и m = 1; n = 20 (нет места для вставки);
- ошибочные данные: буква вместо числа; m = 0; n = 21.
